# 长征疾行 · 二万五千里

红军主题横版跑酷 + 长征历史知识问答的网页小游戏，单文件实现，无外部依赖。

**在线试玩：** https://luoqingjiu520.github.io/changzheng-dash/

![长征疾行开始页](screenshot.png)

## 玩法

- 空格 / ↑ / W 或点击画面：跳跃，空中再按一次二段跳
- ↓ / S：滑行；空中按下快速下坠
- 手机：轻触画面或「跃」跳跃，按「伏」滑行
- 拾取「战鼓」自动进入 3.6 秒冲锋：无敌、加速、撞碎障碍
- 贴近山石跃过会触发「惊险连闪」，连击越高，额外加分越多
- 每局 5 道红旗问答门，题库 10 题随机抽 5；答对得 8 秒护盾 + 星火 ×15
- 3 点士气，走完 25,000 里到达会宁会师即通关

## 主题与内容

- 红军小战士：灰蓝军装、八角帽红星、红领章、绑腿、挎包与红旗
- 路线：瑞金 → 湘江 → 遵义 → 赤水 → 金沙江 → 泸定桥 → 夹金山 → 草地 → 会宁
- 沿途地标剪影：瑞金塔、遵义会址、赤水渡船、泸定桥、雪山、草地行军队列、会宁城门
- 结算页包含历史问答回顾与冲锋、连闪战绩
- 题库基于课程参考资料整理，仅作学习与课程作业用途

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装依赖或联网。受浏览器自动播放策略限制，音效会在第一次点击后开始。
